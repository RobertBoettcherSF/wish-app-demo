# Wish App v0.1.0 static demo

This repository publishes the synthetic Wish App v0.1.0 static build so it can be opened in a browser. It is a demo distribution only. The application source and its history stay in the private draft.

The interface is a five-tab shell with a visible version, Debug, decorative Devanagari rain, and tap sounds. Wishes are not stored. This build contains no personal wishes, names, media, or accounts.

## Version

`version.txt` and the on-screen badge both read `v0.1.0`.

## Font

The rain uses Noto Sans Devanagari Regular, copyright 2010–2020 Google Inc., under the SIL Open Font License, Version 1.1. The font file and the full license are in `fonts/`.

## Paths

Scripts, styles, and the font use paths relative to this directory, so the same files work when the site is opened from a subdirectory.
