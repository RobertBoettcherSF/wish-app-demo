# Wish App v0.2.0 static demo

This repository publishes the synthetic Wish App v0.2.0 static build so it can be opened in a browser. It is a demo distribution only. The application source and its history stay in the private draft.

The interface is a five-tab shell with a visible version, Debug, decorative Devanagari rain, and tap sounds. A wish can be saved in this browser as text, a theme, and an optional priority label. On this shared public page, use fictional examples only. Storage here is not private, not encrypted, and not permanent. The browser can remove it. This build contains no personal wishes, names, media, or accounts.

## Version

`version.txt` and the on-screen badge both read `v0.2.0`.

## Font

## Paths

Scripts, styles, and the font use paths relative to this directory, so the same files work when the site is opened from a subdirectory.
