# Wish App v0.3.0 static demo

This repository publishes the synthetic Wish App v0.3.0 static build so it can be opened in a browser. It is a demo distribution only. The application source and its history stay in the private draft.

The interface is a five-tab shell with a visible version, Debug, decorative Devanagari rain, tap sounds, and English or German labels. A wish can be saved in this browser as text, a theme, and an optional priority label. Settings can prepare a backup file of those wishes and import one after a preview. The file is not encrypted, nothing is uploaded, and this app cannot confirm that the browser saved the file on disk. On this shared public page, use fictional examples only. Storage here is not private, not encrypted, and not permanent. The browser can remove it. This build contains no personal wishes, names, media, or accounts.

## Version

`version.txt` and the on-screen badge both read `v0.3.0`.
